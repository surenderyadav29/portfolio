Core ERP Modules

Student Lifecycle

Manages admissions, dynamically links specific courses, tracks total fees paid, and handles unique identification.

Employee Directory

Handles staff recruitment details, departmental allocations (HR, Academics, Finance), and unique corporate profiles.

Financial Tracker

Processes total course fees structure, dynamic financial data representations, and checks unpaid balances.

Advanced Reports

Generates structural business insights like dynamic student enrollments, course duration stats, and active metrics tracking.

Technical Deep Dive & Insights

  • 🔥 **Relational Integrity:** Implemented foreign key constraints (`course_id` inside `students` table) mapping data dynamically with proper database normalization schemes.
  • 🚀 **Full CRUD Capabilities:** Programmed scalable operational buttons (Add, Update, Delete, Clear) mapping directly to standard SQL commands executed safely through the python connector.
  • 🔍 **Real-time Live TreeView Sync:** Integrated dynamic asynchronous refresh triggers that automatically fetch the updated data array directly from MySQL database and inject it into Tkinter UI component.
  • 📈 **Analytical Aggregations:** Engineered automated calculations in the report section tracking live student density per course, duration matrices, and cumulative operational fees.
  • 🛠️ **Data Security & Auto-Log:** Integrated automatic SQL timestamping (`created_at`) utilizing standard database constraints for structural accountability.
